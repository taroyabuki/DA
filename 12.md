## 講義資料

### 基本形と使用例

```python
class Node:
    """２分探索木のノード"""

    def __init__(self, key, value, left=None, right=None):
        """コンストラクタ"""
        self.key = key      # キー
        self.value = value  # 値
        self.left = left    # 左ポインタ（左の子への参照）
        self.right = right  # 右ポインタ（右の子への参照）


class BinarySearchTree:
    """２分探索木"""

    def __init__(self):
        """初期化"""
        self.root = None    # 根

    def add(self, key, value):
        """キーがkeyで値がvalueのノードを挿入"""

        def add_node(node, key, value):
            """nodeを根とする部分木にキーがkeyで値がvalueのノードを挿入"""
            if key == node.key:
                return False

            elif key < node.key:
                if node.left is None:
                    node.left = Node(key, value)
                    return True
                else:
                    return add_node(node.left, key, value)

            else:
                if node.right is None:
                    node.right = Node(key, value)
                    return True
                else:
                    return add_node(node.right, key, value)

        if self.root is None:
            self.root = Node(key, value)
            return True
        else:
            return add_node(self.root, key, value)
```

```python
tree = BinarySearchTree()

print(tree.add(11, "A"))  # True
print(tree.add(5, "B"))   # True
print(tree.add(15, "C"))  # True
print(tree.add(5, "X"))   # False
```

参考書の2分探索木にはバグがあり，根以外の重複がある場合に False にならない．上記コードは修正済み．

## プレゼン課題

上記の基本形のコードを使って解答してください．

### 1

指定した `key` をもつノードを探索し，存在する場合はその値（`value`），存在しない場合は `None` を返す方法を説明し，メソッド `search(self, key)` で実装してください．

### 2

`key` と `value` の組を，`key` の昇順に表示する方法を説明し，メソッド `dump(self)` で実装してください．

### 3

最小のキーを求める方法を説明し，メソッド `min_key(self)` で実装してください．

### 4

指定した範囲のキーをもつノードを，キーの昇順に取り出す方法を説明し，メソッド `range_search(self, low, high)` で実装してください．

`range_search(self, low, high)` は，`low <= key <= high` を満たすノードの `(key, value)` の組をリストで返すものとします．

♠また，ハッシュ表で同じ範囲検索を行う場合，なぜ二分探索木より扱いにくいかを簡単に説明してください．
