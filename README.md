## 参考書

- **柴田望洋『新・明解Pythonで学ぶアルゴリズムとデータ構造』（SBクリエイティブ, 第2版, 2025）** 旧版も可．紙版が図書館にある．
- 近藤嘉雪『定本Cプログラマのためのアルゴリズムとデータ構造』（SBクリエイティブ, 1998） Pythonで実装してもしょうがないようなデータ構造，アルゴリズムもC言語で実装すると勉強になる．そういうときに役立つ．グラフが扱われていないのが残念．紙版が図書館にある．
- 石畑清『アルゴリズムとデータ構造』（岩波書店, 1989） 名著．紙版が図書館にある．
- **（CLRS）** Cormen, Leiserson, Rivest, and Stein. Introduction to Algorithms. The MIT Press, 4th, 2022. コルメン，ライザーソン，リベスト，シュタイン著. 浅野哲夫ほか訳『アルゴリズムイントロダクション』（近代科学社, 第4版, 2024） 世界的に使われる標準的アルゴリズム教科書．旧版も可．紙版とオンライン版（旧版）が図書館にある．
- アルゴリズム図鑑（iOS, iPadOS, Android） 無料版でもだいたい使える．
- オンラインジャッジ
    - 渡部有隆『プログラミングコンテスト攻略のためのアルゴリズムとデータ構造』（マイナビ出版, 2015） 紙版とオンライン版が図書館にある．
    - 米田優峻『競技プログラミングの鉄則』（マイナビ出版, 2022） 紙版が図書館にある．
